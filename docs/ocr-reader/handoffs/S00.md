## 2. Hợp đồng kỹ thuật xác lập (Contract)

1. **Số liệu Baseline đã khóa:**
   - **Baseline APK:** `75.347.472` bytes (SHA256: `802710A7387288FF3ADB1F31D09550151B716FC4FB957392B72FB5030FE289B8`)
   - **Baseline AAB:** `44.641.170` bytes (SHA256: `5B5D2A6501A14FBD0EBFA4644AF98CE55BAA8933B0F39EFECFB30C9B1F9F115E`)
2. **Ngưỡng dung lượng (Size Gates):**
   - **Trần cứng (Hard Limit):** Tăng tối đa **+10.000.000 byte** (10,0 MB thập phân). APK candidate tối đa: **85.347.472 byte**. Nếu vượt: Script trả mã lỗi exit 2, Gate đánh giá `FAIL`.
   - **Cảnh báo (Warning Threshold):** Tăng **+8.000.000 byte** (8,0 MB thập phân). APK candidate cảnh báo: **83.347.472 byte**. Còn lại 2 MB dự phòng rủi ro.
3. **Lệnh thực thi đo đạc chuẩn:**
   - So sánh mặc định: `pwsh -File "scripts/measure_ocr_size.ps1"`
   - Xuất JSON: `pwsh -File "scripts/measure_ocr_size.ps1" -Json`
   - Ghi baseline mới: `pwsh -File "scripts/measure_ocr_size.ps1" -RecordBaseline`

## 3. Kiểm thử và Kết quả thực tế

1. **Build Baseline thực tế:**
   - Lệnh: `.\gradlew.bat :app:assembleRelease :app:bundleRelease --console=plain`
   - Kết quả: `BUILD SUCCESSFUL` (thời gian build: 15s - 1m).
2. **Kiểm thử script đo với artifact đồng nhất (Self-comparison):**
   - Lệnh: `pwsh -File "scripts/measure_ocr_size.ps1"`
   - Kết quả thực:
     - APK Delta: `0 bytes (0,00%)`
     - AAB Delta: `0 bytes`
     - Gate Status: `PASS - Delta (0 bytes) is within budget (10000000 bytes max).`
3. **Kiểm thử xử lý khi thiếu artifact (Missing artifact failure test):**
   - Lệnh: `pwsh -File "scripts/measure_ocr_size.ps1" -CandidateApk "non_existent.apk"`
   - Kết quả thực: Throw exception rõ ràng: `Artifact file not found: 'non_existent.apk'`
   - Lệnh: `pwsh -File "scripts/measure_ocr_size.ps1" -BaselineApk "missing_baseline.apk"`
   - Kết quả thực: Throw exception rõ ràng: `Artifact file not found: 'missing_baseline.apk'`
4. **Kiểm thử xuất JSON (JSON mode test):**
   - Lệnh: `pwsh -File "scripts/measure_ocr_size.ps1" -Json`
   - Kết quả thực: Trả về JSON object đầy đủ các trường `GateStatus`, `GateReason`, `DeltaApkBytes`, `Breakdown`.

## 4. Giới hạn (Limitations)

- Môi trường Windows cục bộ chưa cấu hình tiện ích CLI `bundletool` độc lập trên PATH hay trong Android SDK; script đã cài sẵn cơ chế tự động tìm `bundletool` nếu được cấu hình bổ sung qua biến môi trường `BUNDLETOOL_PATH`. Kích thước AAB và APK đầy đủ 2 ABI đã được đo trực tiếp với độ chính xác đến từng byte.
- Không bật R8/Proguard để giữ nguyên môi trường đo khách quan theo quy định kế hoạch.
